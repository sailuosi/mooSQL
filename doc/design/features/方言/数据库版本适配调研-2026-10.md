## 1. 结论摘要

mooSQL v8.2 通过 **MySQL Family / PostgreSQL Family + 独立方言** 覆盖约 20 个已注册产品。协议兼容层面大多可连接市面新版服务器，但此前 **DBVersion 元数据、`doc/README` 短表、部分驱动钉版本** 落后于 2026-10 市面线。

本轮已完成：

1. 本调研报告落地  
2. 刷新 MySQL / PostgreSQL / SQL Server / Oracle / ClickHouse / OceanBase / TDengine 的 `DBVersion` 目录  
3. 对齐对外文档中的推荐服务器版本与 SonnetDB 条目  

**未做（backlog）**：驱动大版本升级、真实库连调冒烟、MariaDB JSON Arrow 旗标放宽。

## 2. 当前支持 vs 市面最新

驱动版本以 `mooSQL.Ext.csproj` 的 net8 / net10 为准（调研日快照）。

### 2.1 主流商业 / 开源

| 产品 | 推荐验证版本 | 目录上限（刷新后） | 运行时关键分支 | Ext 驱动（现代 TFM） | 市面最新（约 2026-10） | 适配性 | 剩余缺口 |
|------|--------------|--------------------|----------------|----------------------|------------------------|--------|----------|
| **MySQL** | 8.4 LTS / 9.7 LTS | 9.7、26.x Innovation | `<8` vs `≥8` 分页 | MySqlConnector **2.6.2** | 9.7 LTS / 8.4 LTS / Innovation **26.7** | 协议可用 | Innovation 日历版仅元数据匹配 |
| **MariaDB** | 11.8 LTS / 12.3 LTS | （无独立 DBVersion；见 MariaDB 文档） | Family 旗标 | 同上 | **13.0.2** Stable；LTS **12.3.3** | 基本可用 | 评估 13.x 开启 JSON `->` |
| **PostgreSQL** | 16 / 18 | **18** | 无大版本 SQL 硬分支 | Npgsql **8.0.9**(net8) / **10.0.3**(net10) | **18.6**（19 Beta） | wire 兼容 | net8 是否升 Npgsql 9/10 |
| **SQL Server** | 2022 / 2025 | **2025 (17.0)** | `≥2012` OFFSET/FETCH | SqlClient **6.1.6** | **SQL Server 2025 (17.x)** | 分页可覆盖 | 升 6.1.7 或评估 7.x |
| **Oracle** | 19c / 23ai / 26ai | **26ai** | `Is12cOrHigher` FETCH | ODP Core **23.7.0**(net6/8) / **23.26.300**(net10) | **Oracle AI Database 26ai** | 12c+ 路径可用 | net6/8 驱动对齐 23.26.x |
| **SQLite** | 3.40+ | 3.45 | LIMIT；窗口 3.24+ | Microsoft.Data.Sqlite **9.0.1** / **10.0.11** | 随包内嵌引擎 | 低风险 | 按需刷新目录上限 |

## 3. 驱动钉版本对照（Ext vs NuGet 最新）

| 包 | Ext net8 / net10 | NuGet 最新（调研日） | 建议 |
|----|------------------|----------------------|------|
| MySqlConnector | 2.6.2 | 2.6.2 | 已齐 |
| Npgsql | 8.0.9 / 10.0.3 | 10.0.3 | net10 齐；net8 可评估升 9.x |
| Microsoft.Data.SqlClient | 6.1.6 | LTS 6.1.7 / STS 7.1.1 | 先补丁 6.1.7，再评估 7.x |
| Oracle.ManagedDataAccess.Core | 23.7.0 / 23.26.300 | 23.26.301 | net6/8 对齐；net10 补丁 |
| DuckDB.NET.Data.Full | 1.4.4 / 1.5.5 | 随 DuckDB 1.5.6 | 补丁级；2.0 单独立项 |
| ClickHouse.Driver | 1.4.0 | 视 NuGet | 冒烟后决定 |
| DM.DmProvider | 8.3.1.47463 | 厂商线 | 跟厂商 |
| Kdbndp_V9 | 10.0.1.921 | 厂商线 | 跟厂商 |

**注意**：`mooSQL.Ext.Core` 驱动钉版本整体 **旧于 Ext**（如 MySqlConnector 2.3.7、Npgsql 8.0.6、SqlClient 5.2.2）。若 Core 为对外主包，对齐策略应单独立项，避免静默改变 NuGet 消费者。
