# 达梦（DM）方言适配

> 面向 **使用者**（如何配置与编写查询）与 **开发人员**（兄弟包结构、与 Oracle 差异）。  
> 关联代码：`ext/src/provides/dialect/DM/`、`DataBaseType.DM = 8`、`DialectFactory`；冒烟：`Tests/TestBug/src/TestExt/DMDialectSmokeTests.cs`。

---

## 1. 概述

mooSQL 通过独立方言树接入 **达梦 DM8**。驱动为官方 NuGet **`DM.DmProvider`**，ADO 命名空间 `Dm`。SQL 以 Oracle 兼容面为主，并启用达梦原生 **LIMIT/OFFSET**、**IDENTITY**、**MERGE**。

| 项 | 说明 |
|----|------|
| 枚举 | `DataBaseType.DM = 8`（既有枚举，非新增） |
| ADO 包 | `DM.DmProvider` **8.3.1.47463**（net451–net10 全 TFM） |
| 参数 | `:name` |
| 标识符 | 双引号 `"ident"` |
| 分页 | `LIMIT n OFFSET m`（非 ROWNUM 三层嵌套） |
| Upsert | ANSI `MERGE INTO … WHEN MATCHED / NOT MATCHED`（`SupportsMergeDialect` 已含 DM） |
| Bulk | `DMBulkCopyee` 封装 `Dm.DmBulkCopy` |
| 自增 | 列 IDENTITY 或序列 `seq.nextval`；`getTableAutoIdSQL` → `IDENT_CURRENT` |

**不继承** `OracleDialect`（ADO 类型不同：`DmConnection` vs `OracleConnection`）。

```
Dialect ← DMDialect
SQLExpression ← DMExpress
SQLSentence ← DMSentence
DbBulkCopy ← DMBulkCopyee
```

## 2. 使用者指南

### 2.1 配置连接

```csharp
using mooSQL.data;

var client = new MooClient();
client.dialectFactory = new DialectFactory();

var dbConfig = new DataBase
{
    dbType = DataBaseType.DM,
    // 默认端口 5236
    DBConnectStr = "Server=127.0.0.1;Port=5236;UserId=SYSDBA;PWD=***"
};

var db = new DBInstance { config = dbConfig, client = client };
db.dialect = client.dialectFactory.getDialect(dbConfig);
db.dialect.dbInstance = db;
db.dialect.db = dbConfig;
db.cmd = new CmdExecutor(db);
```

`setDBtype(string)` 识别：`DM` / `DAMENG` / `达梦`。

测试辅助：

```csharp
var kit = DBTest.useDMDialectOnly(); // 仅拼 SQL
var live = DBTest.useDM();           // 读环境变量 DM_CONN，或传入连接串
```

### 2.2 与 Oracle 的主要差异

| 能力 | 达梦落地 |
|------|----------|
| 分页 | `LIMIT` / `OFFSET`（Oscar/MySQL 同路） |
| 多行 INSERT | 标准 `VALUES (…),(…)` |
| EXISTS 标量 | 仍用 `FROM DUAL`（兼容稳妥） |
| Bulk | 有原生 `DmBulkCopy`，非 Fallback |
| Catalog | `user_*` / `all_tab_columns`；`IDENTITY_COLUMN` |

### 2.3 常用查询形态

```csharp
var cmd = db.useSQL()
    .select("id, name")
    .from("t_users")
    .where("name", "alice")
    .setPage(10, 2)
    .toSelect();
// → … LIMIT 10 OFFSET 10，参数 :…
```

## 3. 开发人员指南

### 3.1 目录

```
ext/src/provides/dialect/DM/
  DMDialect.cs
  DMExpress.cs
  DMSentence.cs
  DMMappingPanel.cs
  DMSQLFunction.cs
  DMClauseTranslator.cs
  Translation/DMMemberTranslator.cs
  entity/DMBulkCopyee.cs
```

### 3.2 注册点

- `DialectFactory`：`DataBaseType.DM → DMDialect`（无 TFM 门控）
- `MemberTranslatorResolver`：`nameof(DMDialect) → DMMemberTranslator`
- 保留 `SupportsMergeDialect` 中的 `DM`

### 3.3 驱动注意

- 包 ID 为 **`DM.DmProvider`**（勿用社区非官方 `DmProvider` fork）
- Factory 类型串：`Dm.DmClientFactory,DM.DmProvider`
- 首期不使用 `DmBulkCopy2` 快装路径

### 3.4 测试

```bash
dotnet test Tests/TestBug/mooSQL.Tests.csproj -f net8.0 --filter "FullyQualifiedName~DMDialect"
```

联调：设置 `DM_CONN` 后 `Live_Crud_When_DM_CONN_Set` 会执行最小 CRUD。
