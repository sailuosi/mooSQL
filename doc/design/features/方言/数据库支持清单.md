# mooSQL 数据库支持清单（Family 视野）

> **状态**：与代码同步（`DialectFactory` / `DataBaseType`，2026-09）  
> **术语**：英文 **Family**（`MySqlFamilyDialect` / `PgFamilyDialect`）；中文「族 / 家族」。  
> **设计依据**：[方言族抽象与MariaDB支持.md](方言族抽象与MariaDB支持.md) · [实施计划](../../plan/方言族抽象与MariaDB支持-实施计划.md)

---

## 1. 总览

mooSQL 通过 **方言（Dialect）** 抹平常见 CRUD / 分页 / 参数 / Bulk 差异。自 v8.2 起，同源协议产品收敛为两大 **Family**：

```
ExtDialect
  ├─ MySqlFamilyDialect          ← MySQL wire + MySqlConnector
  │    ├─ MySQLDialect
  │    ├─ MariaDBDialect
  │    ├─ TiDBDialect
  │    └─ OBMySQLDialect         （Bulk → Fallback）
  │
  └─ PgFamilyDialect             ← PG SQL 共性；ADO 可换驱动
       ├─ NpgsqlDialect          （Bulk → NpgBulkCopyee / COPY）
       ├─ CrateDBDialect         （: Npgsql；Bulk → Fallback）
       └─ OpenGaussDialect       （含 GaussDB 枚举；Bulk → Fallback）
```

其余产品为 **独立方言**（自有驱动与 SQL 模板），不挂上述两族。

| 分类 | 数量（已注册） | 说明 |
|------|----------------|------|
| MySQL Family | 4 枚举 + PolarDB 复用 | 含独立枚举与「无枚举复用」 |
| PostgreSQL Family | 4 枚举（含 GaussDB） | OpenGauss / GaussDB 共一方言类 |
| 独立方言 | 10+ | SQL Server、Oracle、国产、分析库、时序等 |
| 枚举占位 / 未注册 | 若干 | Access、DB2、Informix、OceanBaseOracle、UX 等 |

---

## 2. MySQL Family

**基类**：`MySqlFamilyDialect`  
**协议 / 驱动**：MySQL wire · **MySqlConnector**  
**默认 Bulk**：`MySqlFamilyBulkCopyee`（具体实现，非抽象）  
**SQL 轮子**：直接复用 `MySQLExpress` / `MySQLSentence` 等（不另抽 Express 抽象层）  
**共性**：`?` 参数、反引号标识符、`LIMIT/OFFSET`、`SupportsMerge() == false`、`IsInsertOrUpdateSupported == true`

| 产品 | `DataBaseType` | 方言类 | Bulk | TFM / 驱动注意 | 文档 |
|------|----------------|--------|------|----------------|------|
| **MySQL** | `MySQL` | `MySQLDialect` | 族默认 `MySqlFamilyBulkCopyee` | 全 TFM | — |
| **MariaDB** | `MariaDB` | `MariaDBDialect` | 族默认 | 差分旗标：Arrow 默认关、RETURNING 开、非原生 JSON | [MariaDB-方言适配.md](MariaDB-方言适配.md) |
| **TiDB** | `TiDB` | `TiDBDialect` | 族默认 | 薄 `TiDBExpress`；端口常 4000 | [TiDB-方言适配.md](TiDB-方言适配.md) |
| **OceanBase（MySQL 模式）** | `OceanBase` | `OBMySQLDialect` | **Fallback** | 覆盖 Bulk | — |
| **PolarDB for MySQL** | 无独立枚举 → 用 `MySQL` | `MySQLDialect` | 族默认 | 云托管兼容 | [PolarDB-方言适配.md](PolarDB-方言适配.md) |

**字符串识别（节选）**：`MYSQL`；`MARIADB` / `玛丽亚`；`TIDB` / `钛DB`；OceanBase 等见 `DataBase.setDBtype`。

**旗标差分（Family 默认 → MariaDB）**

| 旗标 | MySQL / TiDB / OB 族默认 | MariaDB |
|------|--------------------------|---------|
| `IsJsonArrowSupported` | `true` | `false`（LTS 保守） |
| `IsInsertReturningSupported` | `false` | `true` |
| `IsJsonNativeBinary` | `true` | `false` |

## 3. PostgreSQL Family

**基类**：`PgFamilyDialect`  
**SQL 共性**：`NpgsqlExpress` / `NpgSentence` 等；`SupportsMerge() == true`  
**ADO**：**不**绑定 `NpgsqlConnection`；由产品实现  
**默认 Bulk**：`DbBulkCopyFallback`（多行 INSERT）

| 产品 | `DataBaseType` | 方言类 | Bulk | TFM / 驱动注意 | 文档 |
|------|----------------|--------|------|----------------|------|
| **PostgreSQL** | `PostgreSQL` | `NpgsqlDialect` | **`NpgBulkCopyee`**（COPY BINARY） | stock Npgsql | — |
| **CrateDB** | `CrateDB` | `CrateDBDialect`（`: NpgsqlDialect`） | **Fallback**（必须覆盖，勿吃 COPY） | PG wire ≥4.2 | [CrateDB-方言适配.md](CrateDB-方言适配.md) |
| **openGauss** | `OpenGauss` | `OpenGaussDialect` | 族默认 Fallback | net8+：`HuaweiCloud.GaussDB`；低 TFM：Npgsql 兼容 | [openGauss-方言适配.md](openGauss-方言适配.md) |
| **GaussDB** | `GaussDB` | 同上 `OpenGaussDialect` | 同上 | 与 openGauss 分枚举、共方言 | 同上 |

## 4. 独立方言（非两族）

| SQLite | `SQLite` | `SQLiteDialect` | Fallback | — | — |

## 5. 兼容复用 / 未独立枚举

| 场景 | 用法 | 说明 |
|------|------|------|
| PolarDB for MySQL | `DataBaseType.MySQL` | 见 PolarDB 文档 |
| PolarDB for PostgreSQL | `DataBaseType.PostgreSQL` | 协议 PG 时 |
| 云 Aurora MySQL / 多数 MySQL 兼容云 | `MySQL` 或后续薄子类 | 无差分需求时用 MySQL |
| 已用 MySQL 枚举连 MariaDB | 仍可用 | **新项目请用 `MariaDB`** |

## 6. 枚举占位 · 未在工厂注册

| `DataBaseType` | 说明 |
|----------------|------|
| `Access` | JetSQL 有代码痕迹，**未** `useDialect` |
| `DB2` / `Informix` | 历史枚举，无现网方言 |
| `OceanBaseOracle` | 仅枚举；OB Oracle 模式未交付 |
| `UX`（优炫） | 仅枚举 |

不纳入「已支持」清单；不承诺排期。

---

## 7. Bulk 策略速查（Family）

| 路径 | 默认 / 覆盖 |
|------|-------------|
| MySQL Family | 默认 `MySqlFamilyBulkCopyee`；**OB** 覆盖 Fallback |
| PG Family | 默认 `DbBulkCopyFallback`；**仅 PostgreSQL/`NpgsqlDialect`** 覆盖 `NpgBulkCopyee`；**Crate** 必须继续 Fallback |
| 其它独立方言 | 各自原生或 Fallback（见 §4） |

---

## 8. 配置入口

```csharp
client.dialectFactory = new DialectFactory(); // 注册全部已支持方言

var db = new DataBase {
    dbType = DataBaseType.MariaDB, // 或 MySQL / PostgreSQL / TiDB / …
    DBConnectStr = "…"
};
```

测试辅助（节选）：`DBTest.useMySQLDB()` / `useMariaDBDialectOnly()` / `useTiDBDialectOnly()` / `usePostgreSQLDB()` / `useCrateDBDialectOnly()` / `useOpenGaussDialectOnly()` 等。
