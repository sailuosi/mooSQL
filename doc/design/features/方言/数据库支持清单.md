# mooSQL 数据库支持清单（Family 视野）

> **状态**：与代码同步（`DataBaseType` / `DialectFactory` / `provides/*` / 双通道，2026-10）  
> **术语**：英文 **Family**（`MySqlFamilyDialect` / `PgFamilyDialect`）；中文「族 / 家族」。  
> **设计依据**：[方言族抽象与MariaDB支持.md](方言族抽象与MariaDB支持.md) · [实施计划](../../plan/方言族抽象与MariaDB支持-实施计划.md)  
> **版本适配调研**：[数据库版本适配调研-2026-10.md](数据库版本适配调研-2026-10.md)  
> **Provider 包**：仓库根目录 [`provides/README.md`](../../../../provides/README.md) · Demo：`demos/ProviderDemo`

## 1. 总览

mooSQL 通过 **方言（Dialect）** 抹平常见 CRUD / 分页 / 参数 / Bulk 差异。同源协议产品收敛为两大 **Family**；常见库由 `ext` 的 `DialectFactory` **默认注册**；少见 / 国外库放在 **`provides/*` 独立 Provider**，应用需显式 `UseXxx()`。

```
ExtDialect
  ├─ MySqlFamilyDialect          ← MySQL wire + MySqlConnector
  │    ├─ MySQLDialect（含 PolarDBMySQL 枚举复用）
  │    ├─ MariaDBDialect
  │    ├─ TiDBDialect
  │    ├─ OBMySQLDialect         （Bulk → Fallback）
  │    └─ AuroraMySQLDialect     （provides/Aurora；显式 UseAuroraMySQL）
  │
  └─ PgFamilyDialect             ← PG SQL 共性；ADO 可换驱动
       ├─ NpgsqlDialect          （含 PolarDBPostgreSQL 枚举复用；Bulk → NpgBulkCopyee）
       ├─ CrateDBDialect
       ├─ OpenGaussDialect       （含 GaussDB）
       ├─ KingBaseDialect
       ├─ AuroraPostgreSQLDialect / CockroachDBDialect / EDBDialect
       │                         （provides/*；显式 UseXxx；Bulk → Fallback）
       └─ …
```

| 分层 | 说明 |
|------|------|
| **ext 默认注册** | 常见 80%：MySQL/PG Family + MSSQL/Oracle/达梦/SQLite/ClickHouse/Taos/… |
| **provides 显式注册** | DuckDB、Aurora、CockroachDB、EDB、Turso；引用包后 `UseXxx()` |
| **枚举身份** | `DataBaseType` 尽量齐全（含未交付产品），供配置 / 双通道识别 |
| **双通道** | `DataBaseType` 枚举 **+** `DataBase.dialectKey` / `DialectKeys.*` 字符串 |

## 2. MySQL Family（ext 默认）

**基类**：`MySqlFamilyDialect`  
**协议 / 驱动**：MySQL wire · **MySqlConnector**  
**默认 Bulk**：`MySqlFamilyBulkCopyee`  
**共性**：`?` 参数、反引号、`LIMIT/OFFSET`、`SupportsMerge() == false`

| 产品 | `DataBaseType` | 方言类 | Bulk | 注册 | 文档 |
|------|----------------|--------|------|------|------|
| **MySQL** | `MySQL` | `MySQLDialect` | 族默认 | DialectFactory | — |
| **MariaDB** | `MariaDB` | `MariaDBDialect` | 族默认 | DialectFactory | [MariaDB](MariaDB-方言适配.md) |
| **TiDB** | `TiDB` | `TiDBDialect` | 族默认 | DialectFactory | [TiDB](TiDB-方言适配.md) |
| **OceanBase（MySQL）** | `OceanBase` | `OBMySQLDialect` | **Fallback** | DialectFactory | — |
| **PolarDB for MySQL** | `PolarDBMySQL` | 复用 `MySQLDialect` | 族默认 | DialectFactory | [PolarDB](PolarDB-方言适配.md) |
| **Aurora MySQL** | `AuroraMySQL` | `AuroraMySQLDialect` | 族默认 | **UseAuroraMySQL** | provides/Aurora |

仍可用 `MySQL` 连 PolarDB / 多数云 MySQL；**新项目优先用独立枚举**（`PolarDBMySQL` / `AuroraMySQL`）。

**MariaDB 旗标差分**：`IsJsonArrowSupported=false`、`IsInsertReturningSupported=true`、`IsJsonNativeBinary=false`。

## 3. PostgreSQL Family

**基类**：`PgFamilyDialect`  
**SQL 共性**：`NpgsqlExpress` / `NpgSentence`；`SupportsMerge() == true`  
**默认 Bulk**：`DbBulkCopyFallback`（仅 stock PostgreSQL 覆盖 `NpgBulkCopyee`）

| 产品 | `DataBaseType` | 方言类 | Bulk | 注册 | 文档 |
|------|----------------|--------|------|------|------|
| **PostgreSQL** | `PostgreSQL` | `NpgsqlDialect` | **COPY** | DialectFactory | — |
| **CrateDB** | `CrateDB` | `CrateDBDialect` | Fallback | DialectFactory | [CrateDB](CrateDB-方言适配.md) |
| **openGauss** | `OpenGauss` | `OpenGaussDialect` | Fallback | DialectFactory | [openGauss](openGauss-方言适配.md) |
| **GaussDB** | `GaussDB` | 同上 | Fallback | DialectFactory | 同上 |
| **人大金仓** | `KingBaseR3` / `R6`（`R8` 仅枚举） | `KingBaseDialect` | Fallback | DialectFactory（非 net451） | [KingBase](KingBase-方言适配.md) |
| **PolarDB for PostgreSQL** | `PolarDBPostgreSQL` | 复用 `NpgsqlDialect` | COPY | DialectFactory | [PolarDB](PolarDB-方言适配.md) |
| **Aurora PostgreSQL** | `AuroraPostgreSQL` | `AuroraPostgreSQLDialect` | Fallback | **UseAuroraPostgreSQL** | provides/Aurora |
| **CockroachDB** | `CockroachDB` | `CockroachDBDialect` | Fallback | **UseCockroachDB** | provides/CockroachDB |
| **EDB** | `EDB` | `EDBDialect` | Fallback | **UseEDB** | provides/EDB |

## 5. 识别：双通道

| 通道 | 载体 | 说明 |
|------|------|------|
| 枚举 | `DataBase.dbType` / `DataBaseType` | `IDialectFactory.useDialect(DataBaseType, …)` |
| 字符串 | `DataBase.dialectKey` / `DialectKeys.*` | `useDialect(string, …)`；忽略大小写 |

解析顺序：`dialectKey`（若非空）→ `dbType` 枚举字典 → 枚举名字符串回落。  
配置：`DBPosition.DbType` 经 `asDBType()`；失败时保留原始串为 `dialectKey`。XML `setDBtype` 含中英文别名；未知类型不再静默落到 MSSQL。

```csharp
var cash = new DBClientBuilder()
    .UseDuckDB()
    .UseAurora()
    .UseCockroachDB()
    .UseEDB()
    .UseTurso()
    .useDataBase(positions)
    .doBuild();
```

## 7. Bulk 策略速查

| 路径 | 默认 / 覆盖 |
|------|-------------|
| MySQL Family | 默认 `MySqlFamilyBulkCopyee`；**OB**、部分 Provider 可覆盖 Fallback |
| PG Family | 默认 Fallback；**仅 stock PostgreSQL** → `NpgBulkCopyee`；Crate / KingBase / OpenGauss / AuroraPG / CRDB / EDB → Fallback |
| DuckDB / ClickHouse / MSSQL / Oracle / DM | 各自原生 Bulk |
| 其它 | 多为 Fallback |

## 9. 配置入口

```csharp
// 常见库：默认 DialectFactory 已够
client.dialectFactory = new DialectFactory();

// 少见库：链式 UseXxx（或 factory.UseXxx）
var cash = new DBClientBuilder()
    .UseDuckDB()
    .useDataBase(new List<DBPosition> {
        new() { Position = 0, DbType = "DuckDB", ConnectString = "Data Source=:memory:" }
    })
    .doBuild();

// 双通道示例
var db = new DataBase {
    dbType = DataBaseType.None,
    dialectKey = DialectKeys.CockroachDB, // 或 "CRDB"
    DBConnectStr = "…"
};
```

测试辅助：`DBTest.use*DialectOnly()`；DuckDB 仅在定义了 `MOOSQL_PROVIDER_DUCKDB` 的测试工程中可用。
